What it does

Remap & macros

Rebind every key and rotary knob, and record multi-step macros.

Layers

Multiple key layouts you can switch between on the fly.

Per-app presets

The active layout follows whichever app is in focus.

Key library

Build a key once, then drop it onto any slot.

Host actions

Launch an app or open a URL straight from a key.

RGB control

Set the backlight modes and colors your pad supports.

Targets the CH57x-family “MINI KeyBoard” keypads (USB vendor ID 0x1189). On Linux the app needs a small one-time setup (a udev rule and an X11 session) — the in-app first-run checklist walks you through it.

Keypad Studio has no analytics or telemetry. Questions or hardware reports: email us.  ·  Releases
